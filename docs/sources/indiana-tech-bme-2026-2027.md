# Current Indiana Tech BME baseline capture

Checked 2026-10-25 through the public 2026–2027 catalog. Source: [Biomedical Engineering, B.S., catalog 22, program 5716](https://catalog.indianatech.edu/preview_program.php?catoid=22&poid=5716&returnto=906).

Direct web requests returned 403 or empty HTTP 202 responses. The available Chrome browser successfully followed Catalog Home → Degree Options → Biomedical Engineering. The general-education section and course-detail panels were expanded. No account or private information was used.

The resulting [baseline YAML](../../data/baselines/indiana-tech-bme-2026-2027.yaml) records factual course codes, titles, credits and paraphrased prerequisites, rather than copying course descriptions. It includes all 35 required core courses, the 13 technical-elective options, general-education structure and selected foundational options. The 89-credit required-course sum plus the 3-credit elective group reconciles to the displayed 92-credit core group; the displayed general-education group is 30 credits and the overall published total is 122.

The general-education framework has three 9-credit groups—communication, analysis and leadership—and a 3-credit global-issues seminar. Several choices are mathematics/sciences, some choices exceed 3 credits, and the page specifies replacement electives when a course overlaps the major. Accordingly, the source totals do not establish a particular student's approved course selection or ABET credit categories.

Verified prerequisite chains include calculus I → calculus II → differential equations/linear algebra; anatomy/physiology I → anatomy/physiology II → cell biology → genetics; physics I → statics → dynamics → biomechanics; and CAD → medical-device design I → medical-device design II, with medical-device design I also preceding senior project I and senior project II.

The current catalog lists three educational objectives, including innovation/entrepreneurship. The separate older public outcomes page lists two. Use the current catalog as the baseline, and preserve this discrepancy for review.

No official semester grid was shown on the captured degree page. The prototype's eight-semester progression is therefore explicitly proposed. Historical 2014–2015 and earlier plans with 128–129 credits are not used as current requirements. The BME 3700 elective's EE 2050 prerequisite is preserved as written; no equivalence to the core ECE 2100 requirement has been inferred.
