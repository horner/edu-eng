# BIO-100 — Review demonstration and public handoff

Date: 2026-10-25

The [live static PoC](https://horner.github.io/edu-eng/) is ready for the faculty discussion described in the [review guide](../review-guide.md). This is a demonstration prepared for review; no faculty approval, feedback, institutional adoption or student attainment is presumed.

## Demonstration evidence

The browser review suite opened all eight studios and inspected decomposition, interfaces, rotating responsibility, root-cause investigation and separate individual/team assessment evidence. Manual review by the application implementer and a separate agent inspected the foundation-to-capstone progression, resources and practice, prerequisites, browse/map shared selection, ordered-list alternative, both institution profiles, both themes, local notes and phone/keyboard use. The [independent review](../independent-review.md) records the actual checkout and observations.

The same reviewer temporarily changed one resource description in YAML. Rebuilding produced exactly one semantic resource update, retained stable IDs and preserved chapters, competencies, program and credit allocations. The edit was restored. `pnpm sync:demo` separately demonstrated a conflicting upstream update, refusal without tracked input changes, explicit bound resolution and preservation of local review metadata.

Checked-in captures: [overview](../review/overview.png), [dark theme](../review/dark-theme.png), [competency map](../review/competency-map.png), and [phone layout](../review/mobile-semester.png). These show the prototype, not learning outcomes.
