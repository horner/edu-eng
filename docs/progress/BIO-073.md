# BIO-073 — See the program before its topics

Date: 2026-10-26

Reviewer feedback: the original graph made it difficult to see the four-year progression among the individual learning areas. A public-page inspection reproduced the issue: all 40 areas shared one auto-fitted canvas, leaving labels small and giving years/studios no visual priority.

## Result

The default map is now a chronological HTML outline: graduate goal, four year stages and eight semester milestones. Goal/year titles are optional schema-checked program YAML fields; semesters and stable academic IDs supply the actual grouping. This sequence represents the proposed educational progression, not invented prerequisite edges or attained mastery.

Opening a semester reveals its individual and team capabilities, with the studio and foundations disclosed on request. Selecting an area retains the existing resource/assessment/progress detail. **Explore dependencies** opens only that area and its immediate prerequisites; earlier layers and related/concurrent links are explicit options. A new exploration resets extra layers. **Back to semester** and **All four years** preserve orientation. Search marks matches within the complete overview rather than removing the year structure.

Hierarchy navigation restores keyboard focus to the new heading or the previously opened semester; closing an area returns to its selection button. Long prerequisite and map labels wrap. No server, login, academic content deletion or native roadmap.sh import was added.
