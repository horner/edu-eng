# BIO-012 — Developer workflow and continuous integration

Date: 2026-10-25

The [developer guide](../developer-guide.md) documents the pinned Node/pnpm runtime, frozen installation, type checking, ESLint, fixtures, curriculum validation, build, browser tests and contributor workflow. The [independent checkout review](../independent-review.md) followed these instructions on snapshot `7b4879c` with its own dependencies and preview server; installation and all documented checks passed without a source repair.

The [Pages workflow](../../.github/workflows/pages.yml) runs verification before publication. Its first integrated [successful run](https://github.com/horner/edu-eng/actions/runs/40207652201) checked the frozen install, types, lint, unit fixtures, curriculum, build, upstream export and browser journeys on a fresh Ubuntu runner. Publication was enabled separately under BIO-091 and the user's authorization to publish this repository.

Invalid fixtures fail deliberately: duplicate YAML keys and wrong scalar types are rejected with a filename; unknown references and dependency cycles are reported; an unreviewed resource cannot be hidden by a ready label. These negative assertions run in `tests/data/model.test.ts`. The final regression suite and deployment evidence are recorded in [BIO-090](BIO-090.md).

Find associated commits with `git log --all --oneline --grep='BIO-012'`.
