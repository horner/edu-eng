# BIO-090 — Automated acceptance and regression checks

Date: 2026-10-25

The [verification workflow](../../.github/workflows/pages.yml) runs a frozen dependency install, TypeScript, ESLint, unit/fixture tests, schema/semantic/credit validation, static build, a byte comparison of repeated curriculum output, pinned Knowledge Navigator strict export verification and Chromium journeys. It saves semantic summaries, validation output and browser reports as `prototype-review`, plus a built Pages artifact. Verification also runs on pull requests; deployment runs only for authorized successful main-branch pushes.

## Negative fixtures and observed results

- `tests/data/model.test.ts` deliberately creates a missing/late prerequisite, a dependency cycle, a broken resource reference, duplicate credits and a metadata-only resource labeled ready. The corresponding validators report errors; the resource error identifies its chapter and missing ID.
- `tests/sync/sync.test.ts` deliberately conflicts local and upstream content and proves unresolved apply leaves inputs untouched. It also covers stale decisions, ID collisions, deletions and unsupported upstream fields/types.
- `tests/data/export-integrity.test.ts` deliberately drops a supported chapter summary, drops an extension resource assignment and changes a sidecar-only resource URL. The same integrity assertion used by the real exporter rejects each alteration with a responsible record/field. An intact fixture passes.
- State and browser tests cover malformed imports without partial mutation, profile isolation, explicit ID migrations, storage failure, no network progress writes, deep-link reload, both views, both themes/profiles, keyboard/phone navigation and all eight studios.

After adding the explicit resource-reference and export-loss regressions, `pnpm test` passed **45 tests in seven files**. Type checking and lint passed. `pnpm export:verify` passed after extracting the existing integrity checks into a testable function; the pinned upstream builder reported zero warnings. The extraction changes no export contract or curriculum data.

The [first integrated GitHub run](https://github.com/horner/edu-eng/actions/runs/40207652201) independently passed the then-current 40 unit fixtures, all six browser journeys, upstream verification, build and deployment. The [fresh-checkout review](../independent-review.md) independently passed that same application snapshot and the content-only/sync demonstrations. The final evidence/regression commit adds five negative/control tests and an explicit CI determinism step; its exact runner/deployment result is recorded by [GitHub Actions](https://github.com/horner/edu-eng/actions) for that commit. A failed verification blocks deployment.
